# Support Fedora Security Sentinel

Fedora Security Sentinel is intended to remain useful as a defensive Linux security tool without requiring payment to run the core scanner.

If the project saves you time or helps you diagnose a system, optional support can help fund:

- Development and maintenance
- Testing on Fedora releases
- Replacement or additional testing hardware
- Domains and hosting for documentation or project pages
- Security-tool research and integration testing
- Time spent improving documentation and troubleshooting workflows
- Keeping useful public tools available without locking the core functionality behind a paywall
